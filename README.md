# ClipFlow

`ClipFlow` 是一个基于 `Electron + Vue3 + TypeScript + Vite` 的桌面效率工具，用于管理剪贴板历史、执行常见文本转换，并维护可复用的常用片段。

## 当前状态

- 当前定位：个人单机使用的桌面效率工具
- 当前阶段：已完成阶段 3 剪贴板历史 MVP，并补齐阶段 4 的结果复制链路
- 当前能力：
  - 可执行 `npm run dev`
  - 可执行 `npm run build`
  - 已接入文本剪贴板历史轮询与本地持久化
  - 支持复制回填、置顶 / 取消置顶、删除单条、清空普通记录
  - 支持应用重启后的历史恢复
  - `Transform` 已支持转换结果复制与轻量状态反馈
- 当前缺口：
  - `Snippets` 仍是壳子和 mock 阶段
  - `Transform` 与真实状态流的进一步整合仍待补齐
  - 工程化收尾仍待继续推进

## 剪贴板历史 MVP 规则

- 仅处理文本剪贴板内容
- 轮询间隔固定为 `1000ms`
- 空字符串和纯空白内容不入库
- 命中重复文本时不新增记录，只刷新原记录的 `updatedAt`
- 普通历史上限固定为 `50`
- 置顶记录不受普通记录上限裁剪影响
- 清空操作默认只清空未置顶记录

## macOS 开发运行状态

当前已验证项目可以在 macOS 开发环境中安装依赖、构建、启动，并使用文本剪贴板历史 MVP。

macOS 当前支持：

- 文本剪贴板历史采集与本地持久化
- 文本复制回填到系统剪贴板
- 置顶、取消置顶、删除单条、清空普通记录
- 应用退出并重新打开后的历史恢复
- `Transform` 转换结果复制

macOS 当前不包含公开分发能力。本项目暂未实现 `.app` / `.dmg` 打包、签名、公证、自动更新、开机启动、托盘或菜单栏常驻。图片、文件、HTML、RTF 等非文本剪贴板历史也不在当前 MVP 范围内。

## 快速启动

```bash
npm install
npm run dev
```

macOS 上如果 Electron 二进制下载不完整，先确认已执行 `npm install`，再执行：

```bash
npm run setup:electron
```

## 快速构建

```bash
npm run build
```

## 已知说明

- 当前仍建议使用 `Node 22.x LTS`
- 运行期存在 Windows 本地缓存目录权限告警，但目前不阻塞开发和构建
- macOS 本地开发依赖安装已配置 Electron 镜像；若出现 `Electron uninstall` 或 `Electron failed to install correctly`，请参考 [项目使用](./docs/项目使用.md)
