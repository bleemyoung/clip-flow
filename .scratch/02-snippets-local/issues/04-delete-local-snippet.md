# 04 — 确认并删除本地 Snippet

**What to build:** 用户可以删除不再需要的 Snippet，但必须先确认；确认删除会永久移除本地记录，取消不会改变数据。

**Blocked by:** 01 — 加载并恢复本地 Snippet 列表。

**Status:** ready-for-agent

- [ ] 用户发起删除时会先看到明确的确认交互。
- [ ] 用户取消删除时，目标 Snippet 与本地数据保持不变。
- [ ] 用户确认删除时，目标 Snippet 从列表和本地数据中移除，重启后不再恢复。
- [ ] 删除不存在的 Snippet 不会破坏其他片段或应用状态。
- [ ] 删除持久化行为有主进程服务自动化测试，确认与取消交互可被验证。
