# 03 — 验证 macOS 开发态启动

**构建内容：** 让开发者可以在 macOS 上以开发模式启动 Electron 应用，并看到渲染层 UI 正常加载。

**阻塞关系：** 01 — 修复 macOS 本地依赖安装与 Electron 二进制准备。

**状态：** done

- [x] 在 macOS 上启动开发命令并确认 renderer dev server 可用。
- [x] 确认 Electron 桌面窗口能打开并加载应用界面。
- [x] 验证关闭最后一个窗口后，macOS 应用生命周期行为符合预期。
- [x] 验证重新激活应用时窗口或剪贴板状态同步行为符合预期。
- [x] 记录开发态启动所需的环境前提和常见失败恢复方式。

## 验证记录

- 用户已在 macOS 上手动执行 `npm run dev`，确认应用页面可以成功打开。
- 用户已确认 `Clipboard` 页面可使用。
- 用户已确认 `Transform` 页面可使用。
- 用户已确认 `Snippets` 页面当前不能新增片段；该限制来自现有功能范围，`Snippets` 仍是壳子和 mock 阶段，不属于 macOS 启动兼容问题。
- 用户已手动执行 `Command+Q` 退出应用，重新打开后仍可成功复制，说明退出后重新启动的基础链路正常。
- 用户已手动执行 `Command+W` 关闭窗口，随后复制新内容并点击 Dock 栏重新激活应用，窗口能重新出现并展示刚刚复制的内容。
- 代码检查确认主进程保留 macOS 应用生命周期分支：关闭最后一个窗口时不主动退出应用，重新激活时可重新创建窗口或同步剪贴板历史快照。
- 开发态启动前提：依赖安装完整，Electron 二进制已准备完成，本地 renderer dev server 端口可监听。
