# 04 — 验证 macOS 文本剪贴板核心能力

**What to build:** 确认当前剪贴板历史 MVP 在 macOS 上可用，包括读取外部复制文本、写回系统剪贴板、去重、置顶、删除、清空和重启恢复。

**Blocked by:** 03 — 验证 macOS 开发态启动。

**Status:** ready-for-agent

- [ ] 从其他 macOS 应用复制文本后，应用能采集并展示该文本。
- [ ] 空文本或纯空白文本不会进入剪贴板历史。
- [ ] 重复复制相同文本时不会新增重复记录，而是更新已有记录。
- [ ] 历史项可以复制回 macOS 系统剪贴板，并能粘贴到其他应用。
- [ ] 复制回填不会立刻再次生成噪声历史记录。
- [ ] 置顶、取消置顶、删除单条、清空普通记录在 macOS 上行为正确。
- [ ] 应用重启后，本地剪贴板历史可以恢复。
- [ ] 如果发现 macOS 特有差异，记录差异并判断是否需要当前 spec 内改造或拆到后续 spec。
