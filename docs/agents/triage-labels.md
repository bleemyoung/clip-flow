# Triage 标签

工程技能使用以下五个 canonical triage 角色。本地 ticket 的 `Status:` 字段使用右列的标签字符串。

| Skill 角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚需评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 范围明确，可交给 agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或决策 |
| `wontfix` | `wontfix` | 不计划处理 |

当工程技能提及某个 triage 角色时，使用本表对应的标签字符串。
