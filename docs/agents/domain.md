# 领域文档

本仓库是单上下文项目。工程技能在探索或实施前，应先读取与当前工作相关的领域文档。

## 优先读取

- 根 `CONTEXT.md`
- `docs/adr/` 下与当前工作相关的 ADR

若上述文件或目录不存在，正常继续；只有 `/domain-modeling` 在确实形成新的领域术语或难以逆转的决策时才创建它们。

## 使用规则

- 在 spec、ticket、测试名称和设计讨论中使用 `CONTEXT.md` 已定义的术语，避免使用其中明确排除的同义词。
- 如发现实现或新决策与 ADR 冲突，必须显式指出冲突，不能静默覆盖。
- 新的领域术语应先通过 `/domain-modeling` 澄清，再写入 `CONTEXT.md`；不要把实现细节放入 glossary。
