# ClipFlow 项目使用

## 环境要求

- Node 版本建议：`22.x LTS`
- 推荐版本：`22.16.0`
- 包管理器：`npm`

当前已在 macOS 上确认过的本地版本：

- Node：`v22.22.3`
- npm：`10.9.8`

## 安装依赖

```bash
npm install
```

项目级 `.npmrc` 已配置 Electron 下载镜像：

```text
electron_mirror=https://npmmirror.com/mirrors/electron/
```

如果 macOS 上曾经中断过依赖安装，或启动时报出 `Electron uninstall` / `Electron failed to install correctly`，通常说明 `node_modules/electron` 只有 npm 包壳，Electron 桌面二进制没有下载完整。可按下面步骤恢复：

```bash
npm install
npm run setup:electron
```

恢复后可用下面命令确认 Electron 二进制已经准备完成：

```bash
node node_modules/electron/cli.js --version
```

如果仍然失败，可以删除本地依赖后重新安装：

```bash
rm -rf node_modules
npm install
npm run setup:electron
```

注意：`rm -rf node_modules` 只应在项目根目录执行，用于删除本地依赖目录，不会删除源码。执行前请确认当前目录是 ClipFlow 项目根目录。

## 启动开发环境

```bash
npm run dev
```

启动后将完成：

- Electron 主进程构建
- preload 构建
- renderer 开发服务启动
- Electron 桌面窗口启动

macOS 本地已手动验证 `npm run dev` 可以打开应用页面。当前页面状态：

- `Clipboard` 可使用
- `Transform` 可使用
- `Snippets` 可以进入页面，但仍是壳子和 mock 阶段，暂不支持新增片段
- 使用 `Command+W` 关闭窗口后，复制新内容并点击 Dock 栏重新激活应用，窗口可重新出现并展示刚刚复制的内容

`Snippets` 不能新增不是 macOS 启动兼容问题，而是当前产品阶段尚未实现常用片段 CRUD 与持久化。

## macOS 当前支持能力

当前 macOS 开发环境已验证支持：

- 文本剪贴板历史采集
- 文本复制回填到系统剪贴板
- 重复文本去重与更新时间刷新
- 空文本或纯空白文本过滤
- 置顶和取消置顶
- 删除单条历史
- 清空未置顶普通历史
- 应用退出并重新打开后的历史恢复
- `Transform` 转换结果复制

当前未发现需要在本 spec 内改造的 macOS 特有文本剪贴板差异。

## macOS 暂不支持或非本次范围

本次目标是让项目在开发者自己的 Mac 上稳定开发运行，不包含面向普通用户的 macOS 公开分发。

非本次范围：

- `.app` 或 `.dmg` 打包
- Apple Developer ID 签名
- Apple 公证
- 自动更新
- 开机启动或登录项能力
- 托盘常驻或菜单栏常驻
- 全局快捷键
- 图片、文件、HTML、RTF 或其他非文本格式的剪贴板历史
- `Snippets` 新增、编辑、删除、复制和本地持久化

其中，生产级 macOS 分发能力应拆到后续分发 spec；非文本剪贴板历史和全局快捷键等深度平台能力也应拆到后续 spec。

## 构建项目

```bash
npm run build
```

构建成功后会生成：

- `dist/main`
- `dist/preload`
- `dist/renderer`

macOS 本地已验证 `npm run build` 可完成：

- TypeScript 类型检查
- Electron 主进程构建
- preload 构建
- renderer 生产构建

如构建时出现 `Permission denied` 并指向 `node_modules/.bin/*` 或其目标脚本，通常是本地依赖可执行权限异常。优先重新安装依赖；如果问题来自迁移后的本地依赖目录，可检查对应 bin 目标文件是否具备可执行权限。

## 调试方式

开发环境下已支持调试模式：

- 启动后自动打开 DevTools
- 支持 `F12`
- 支持 `Ctrl + Shift + I`

## 当前目录说明

```text
ClipFlow/
  main/       Electron 主进程
  preload/    预加载桥接
  renderer/   Vue3 渲染层
  shared/     跨层共享类型与常量
  docs/       项目文档沉淀
```

## 页面入口说明

- HTML 入口：`renderer/index.html`
- Vue 启动入口：`renderer/src/main.ts`
- 首页根组件：`renderer/src/App.vue`

## 常见排查入口

### 页面白屏

优先检查：

- preload 是否正常加载
- DevTools Console 是否有红色报错
- `window.clipflow` 是否可用

### 启动失败

优先检查：

- Node 版本是否满足要求
- `electron.vite.config.ts` 入口配置是否完整
- 依赖是否安装完成
- Electron 二进制是否安装完整，可通过 `node node_modules/electron/cli.js --version` 验证

### 构建失败

优先检查：

- TypeScript 类型错误
- 路径别名配置
- 入口文件路径是否变更
- 当前 Node 版本是否满足 `22.x LTS` 要求
