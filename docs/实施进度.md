### 阶段 3：剪贴板历史

状态：已完成 MVP，macOS 已手动验证

已完成：

- 在 `main` 层接入文本剪贴板轮询
- 轮询间隔固定为 `1000ms`
- 本地持久化到 `app.getPath('userData')/clipboard-history.json`
- 完成历史记录入库与应用重启恢复
- 完成重复文本去重，重复时仅刷新原记录时间
- 完成普通历史上限 `50`

当前固定规则：

- 应用主动复制回填时会忽略本次写入，避免立即重复入库

### 阶段 5：常用片段

状态：离线 V1 与桌面端手动验收已完成

功能定位：

- 面向个人单机使用的本地文本片段库
- 与 `Clipboard` 的“刚复制过什么”不同，这里管理“之后还会反复使用什么固定文本”
- 与 `Transform` 的“当前文本怎么处理”不同，这里管理可长期复用的模板和话术

已确认的离线 V1 方案：

- 本轮只实现离线 `Snippets`，不接入 Java 后端、登录或同步
- 数据由 Electron 主进程持久化到 `app.getPath('userData')/snippets.json`，并通过 `preload` 暴露受控 API
- 完成列表与关键词搜索、新增、编辑、删除、复制到系统剪贴板，以及应用重启后的数据恢复
- 标题和内容去除首尾空白后均不能为空；允许重复标题和内容
- 列表按 `updatedAt` 倒序排列；删除需二次确认，暂不提供撤销或回收站
- 沿用 `id`、`title`、`content`、`createdAt`、`updatedAt` 字段；不引入标签、置顶、分类、变量或快捷键
- 本地数据仅用于当前离线版本验证，未来接入后端时可以直接废弃，不做迁移或同步

已完成：

- 列表已接入本地真实数据，支持按标题和内容搜索
- 新增、编辑、删除确认、复制与重启恢复已实现
- 独立 JSON 持久化与主进程服务、桥接、页面交互测试已完成
- macOS 手动验证创建、搜索、编辑排序、删除取消与确认、跨应用粘贴、重启恢复；证据见 `.scratch/03-java-snippets-backend/issues/00-offline-snippets-acceptance.md`

明确后置：

- Electron 接入后端前的模式切换与后端完整 CRUD 设计
- 登录、游客与账户数据切换、离线同步、迁移与冲突处理

### 阶段 5.5：独立 Java Snippets API

- `server/` 使用 Java 21、Spring Boot 3.5、Maven Wrapper、PostgreSQL、Flyway 和 Testcontainers

- `POST /api/snippets` 创建；`GET /api/snippets?keyword=` 列表和关键词查询
- 统一 400 错误、UTC 时间、OpenAPI 与人可读接口示例已完成
- macOS 上 5 项真实 PostgreSQL 集成测试通过；HTTP 创建、查询、无效输入、容器重启和完整 Compose 停启持久化均已验证
- 具体启动命令见 `server/README.md`；00–05 验收记录见 `.scratch/03-java-snippets-backend/issues/`
- Windows 运行与桌面端后端接入均未验证，不列为本阶段完成项

## macOS 验证情况

已完成：

- `npm run setup:electron` 可恢复 Electron 二进制安装
- `npm run build` 已在 macOS 上通过
- `npm run dev` 已在 macOS 上手动验证可打开页面
- `Command+W` 关闭窗口后，点击 Dock 栏可重新激活窗口并展示新复制内容
- `Clipboard` 和 `Transform` 在 macOS 上可使用
- 当前未发现需要在本 spec 内改造的 macOS 文本剪贴板差异

当前限制：

- macOS 公开分发尚未实施
- `.app` / `.dmg` 打包、签名、公证、自动更新、开机启动、托盘或菜单栏常驻均未实施
- 图片、文件、HTML、RTF 等非文本剪贴板历史不在当前 MVP 范围
- Java API 与 Electron 离线 Snippets 尚未联动
